# Спецификация Karavan

## Совместимость API

Karavan должен предоставлять API, совместимый с OpenRouter для поддерживаемых
методов. Форматы запросов и ответов, названия полей, HTTP-коды и структура ошибок
должны соответствовать API OpenRouter.

При добавлении или изменении методов API контракт необходимо проверять по
актуальной официальной документации OpenRouter. Совместимость должна проверяться
тестами для поддерживаемых сценариев.

Расширения Karavan и любые отклонения от API OpenRouter должны быть явно
задокументированы в README.md. Это требование задаёт направление разработки
и не означает, что все методы OpenRouter уже реализованы.
