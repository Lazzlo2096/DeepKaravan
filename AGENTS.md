# Инструкции для разработки

## Совместимость с OpenRouter

- При изменении API соблюдай требования совместимости из [SPEC.md](SPEC.md).
- Проверяй контракт по актуальной официальной документации OpenRouter:
  форматы запросов и ответов, названия полей, HTTP-коды и структуру ошибок.
- Покрывай совместимость тестами для затронутых поддерживаемых сценариев.
- Явно документируй расширения Karavan и отклонения от API OpenRouter в README.md.
- Не заявляй полную совместимость без проверки соответствующих методов.
